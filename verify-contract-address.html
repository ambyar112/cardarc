How to Check Your App:

  1. Open your app (cardarc.vercel.app)
  2. Press F12 to open DevTools
  3. Go to Console tab
  4. Paste this command:
console.log('ARC_CARDS_ADDRESS:', import.meta.env.VITE_CONTRACT_ADDRESS);
console.log('MARKETPLACE_ADDRESS:', import.meta.env.VITE_MARKETPLACE_ADDRESS);

OR check Network tab:

  • Try to mint a card
  • Look for the transaction
  • Check "To" address in transaction
  • Should be 0x37D4... (NEW) not 0x8757... (OLD)

✅ If Seeing OLD Addresses:

  1. Hard Refresh: Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
  2. Clear Cache: F12 → Network tab → Disable cache checkbox
  3. Verify Vercel Env Vars:
    • Go to Vercel Dashboard
    • Settings → Environment Variables
    • Confirm VITE_CONTRACT_ADDRESS = 0x37D4259...
    • Confirm VITE_MARKETPLACE_ADDRESS = 0xD85E15A...
  4. Manual Redeploy:
    • Deployments tab
    • Click "..." on latest deployment
    • Click "Redeploy"
    • Wait ~2 minutes
