🔍 Contract Address Checker

Verify which contract addresses are loaded on the live site

1 Open Live Site
Open cardarc.vercel.app in a new tab
2 Open Browser Console
Press F12 (or Right-click → Inspect → Console tab)
3 Paste & Run This Code
Copy this entire code block and paste it into the console:
console.log('=== CONTRACT ADDRESSES CHECK ==='); console.log('Contract:', import.meta.env.VITE_CONTRACT_ADDRESS); console.log('Marketplace:', import.meta.env.VITE_MARKETPLACE_ADDRESS); console.log(''); console.log('EXPECTED:'); console.log('Contract: 0x37D4259aae3F7B79BFc414A98A58ed050Ca3Ed3A'); console.log('Marketplace: 0xD85E15A66C9F2f6a0E4c6C7472a6C0Fe58845438'); console.log(''); if (import.meta.env.VITE_CONTRACT_ADDRESS === '0x37D4259aae3F7B79BFc414A98A58ed050Ca3Ed3A') { console.log('✅ CONTRACT ADDRESS CORRECT!'); } else { console.log('❌ CONTRACT ADDRESS WRONG! Need to update Vercel env vars!'); } if (import.meta.env.VITE_MARKETPLACE_ADDRESS === '0xD85E15A66C9F2f6a0E4c6C7472a6C0Fe58845438') { console.log('✅ MARKETPLACE ADDRESS CORRECT!'); } else { console.log('❌ MARKETPLACE ADDRESS WRONG! Need to update Vercel env vars!'); }

✅ If BOTH addresses are CORRECT:
Great! Environment variables are up to date. If you're still having issues, the problem is elsewhere. Clear browser cache (Ctrl+Shift+R) and try again.
❌ If ANY address is WRONG:
Vercel environment variables need to be updated! Follow the instructions in FIX_VERCEL_NOW.md to update env vars and redeploy.
💡 Quick Tip: If addresses are wrong, you need to:
1. Go to Vercel Dashboard → Project Settings → Environment Variables
2. Update VITE_CONTRACT_ADDRESS and VITE_MARKETPLACE_ADDRESS
3. Redeploy from Deployments tab
4. Hard refresh browser (Ctrl+Shift+R)
